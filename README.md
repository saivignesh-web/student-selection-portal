
# Student Selection Portal

A full-stack Student Selection Portal.

The project includes a responsive frontend for managing student profiles and a REST API backend that provides CRUD operations for student records.

## Features

### Frontend
- Responsive student selection interface
- Display student profiles
- Add new students
- Edit existing student profiles
- Delete students
- Search students by:
  - Name
  - Roll number
  - Department
- Profile photo upload
- Skills management
- GitHub and LinkedIn links
- Student year and department details
- Dynamic profile selection

### Backend
- REST API built with Node.js and Express
- CRUD operations for student records
- JSON-based data persistence
- Input validation
- Error handling
- CORS support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- REST API
- JSON
